# 2026-10-23 入口层体验（P3 4a–4e）

清单新增的 P3 段，五条都不动核心逻辑，全是"人的入口"。

> 清单原话：120 个命令本身不臃肿，功能是正交的。问题集中在"人的入口"。

## 4a：`astra bili --help` 报 UNKNOWN_COMMAND

**清单说是"唯一真正卡住使用者的地方"** —— 每次新会话都要重新想起
`astra help bili` 这个写法，而没人猜得到。

修法：`main()` 在路由之前，如果 args 只有一个词且那个词是个组名，
就把 args 重写成 `help <组>`。

有个坑：重写之后 `wantsHelp` 仍然为 true，于是会走"展示 help 命令自己的说明"
那个分支，吐出来的是 help 的 meta，不是 bili 的子命令。加了 `isGroupHelp` 标记排除。

未知子命令（`astra bili foo`）的 hint 也改了：之前给全局顶层命令清单，
在 `bili foo` 这个上下文里没有任何帮助；现在给该组的子命令。

## 4b：`bili.template` 名字歧义

加了 `bili.audio-template` 之后，`bili.template` 就不再是"模板"而是"视频模板"，
但键名没变。两个键并列时语义不对等 —— 看配置的人得先猜哪个管视频。

`bili.video-template` 是正式名，`bili.template` 保留为别名：

```ts
const ALIASES = { 'bili.template': 'bili.video-template' }
```

读写都走正式名，但**写老名时也写一份新名**（反过来也成立）——
老版本 astra 读的还只是 `bili.template`，升级后回退不该丢配置。

## 4c：doctor 展开模板

之前改完 `bili.audio-dir` / `bili.audio-template`，**只能真下一个文件才知道落点对不对**。
实测踩过：`--to bili` 用错模板落成 `<标题>/01.mp3`，看 doctor 完全发现不了。

现在 doctor 多一段 `bili.paths`，用固定的假数据把两套模板展开：

```
bili.dir            .../video
bili.audio-dir      跟随 music.dir（.../music）
  video-template    → .../video/示例UP主/示例视频标题/01.mp4
  audio-template    → .../music/示例UP主/示例视频标题/01 示例分P.mp3
```

`bili.audio-dir` 为空时显示"跟随 music.dir（…）"，不留空 —— 空白看起来像坏了。

## 4e：`--table`

只给高频查询加，默认仍是 JSON。

关键设计：**`table` 不进 `data`**。它放在 `CommandResult` 顶层：

```ts
export interface CommandResult {
  data: unknown
  warnings?: string[]
  table?: { headers: string[]; rows: ... }   // 只影响显示
}
```

第一版我把它塞进 `data` 里了，结果不加 `--table` 时 JSON 里也混进一个 `table` 字段 ——
污染了返回结构。清单验收明确写着"不加 `--table` 时输出与现在完全一致"。

### 表格对齐踩了两次

**第一次**：分隔线用 `'─'.repeat(列宽)`。`─` 是宽字符（占 2 格），
按列宽重复 N 次会变成 2N 格，整行比数据行宽一倍。改用 ASCII `-`。

**第二次**：测试自己写歪了三次。先是拿 `length` 算宽度（中文算 1 格，列会歪），
然后探测"第二列起点"的算法把 `abcd` 的第二个字符当成了第二列。

最后换了个直白的判据：**从行首到第二列内容的显示宽度必须相同**。
并且测试数据选成"字符数相同、显示宽度不同"的两行（`中文歌名` 4 字/8 格
vs `abcd` 4 字/4 格）—— 这样用 `length` 算的话测试会红，用显示宽度算才对。

验证过：把 `width` 改回 `s.length`，这条测试立刻失败。

## 验证

```
astra bili --help          → 27 个子命令（三种写法都通）
astra bili foo             → hint 里是 bili 的子命令
bili.template / bili.video-template → 读写互通
doctor                     → bili.paths 展开出两条示例路径
jobs --table               → 表格；不加时 JSON 里没有 table 字段
```

`npm run check` 349 项全过。四条防线验过能变红：
`commandGroup` 去掉 → 1 条；别名去掉 → 1 条；`width` 改 `length` → 1 条。

## 一个观察

这五条里 4a 最有价值 —— 它不涉及任何业务逻辑，但它是"每次新会话都要重新想起
一个没人猜得到的写法"这种慢性摩擦。功能再全，入口打不开也没用。
