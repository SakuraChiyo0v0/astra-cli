# 2026-10-29 comic 域纯 TS 落地

## 做了什么

新增 `astra comic`（get / info / search / doctor），用 TypeScript 直接打移动端 API，
**不调用** NAS 上的 `jmcomic-web` 容器（用户打算后续下掉那个）。

## 为什么不包 Python jmcomic

用户明确要方案 B：纯 TS、零容器依赖。Hermes 里只有单文件 `astra.mjs`，
再塞 Python 运行时和 `jmcomic` 包会把部署变双栈。

## 关键实现取舍

| 点 | 决定 | 原因 |
|-|-|-|
| AES | `aes-256-ecb`，密钥是 md5 **hex 的 ASCII**（32 字节） | 跟公开实现一致；不是 hex 解码后的 16 字节 |
| 解混淆 | ffmpeg filter（竖条重排），不引入 sharp | 单文件产物塞不进原生模块；Hermes 已有 ffmpeg（B 站要用） |
| 域名 | 启动时尝试 TOS 域名清单，失败用内置列表 | 域名会过期 |
| cookies | 先打 `/setting` 收 Set-Cookie | 移动端要求带 cookie，否则会跳到固定本子 |

## 踩过的坑（实现时）

- 以为密钥是 md5 的 16 字节 raw digest → 解出来全是乱码。实测必须用 hex 字符串的 UTF-8。
- album API 适配层里 `scramble_id` 恒为 `'0'`，真正值要打 `/chapter_view_template`（另一套 token secret）。
- 图片 URL 要带 `?v=<ts>`，否则 CDN 可能给空体。
