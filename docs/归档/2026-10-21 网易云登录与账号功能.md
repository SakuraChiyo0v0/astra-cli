# 2026-10-21 网易云登录与账号功能

## 加了什么

- 扫码登录（weapi 加密通道）、会话保存、账号状态、登出
- 我的歌单（自建 + 收藏，实测 32 个）
- 每日推荐（带"为什么推给你"）、我喜欢的音乐、批量查喜欢状态
- 二维码出 PNG 文件，交给 Hermes 用 `MEDIA:<路径>` 发图

## 踩过的坑

**以为要照搬 astrahub 的 eapi 才能登录，实测扫码走的是 weapi。**
`/weapi/login/qrcode/unikey` + `/weapi/login/qrcode/client/login` 仍然可用（unikey 返回 200、未扫码返回 801）。
eapi 那条路是给账号维度的播放地址用的，这次没用到。

**以为终端画二维码就能扫，实测不行。**
半块字符在聊天窗口里既扫不出来、又会因为字体宽度错位。改成 PNG（自己写的 PNG 编码器，不引图片库），
用 ffprobe 当第三方裁判验证宽高与格式。

**以为 `liked/check` 返回等长的 0/1 数组，实测返回的是"已红心的子集"。**
实测：传 3 个 id，只有一个红心过时返回 `{"ids":[2068218436]}`，长度只有 1。
astrahub 的注释里也写了同样的结论（"不是旧 SDK 注释所说的等长 0/1 数组"）。按集合包含判断，长度不等是正常的。

**以为登录后能拿到更高音质，实测不会。**
登录影响的是"能看见什么"（私人歌单、日推、红心），不是取链音质。取链仍走洛雪音源，
VIP 曲目能不能拿到无损由音源决定，不由账号决定。

**二维码有效期 5 分钟，测试时第一次就过期了。**
`login start` 是把 unikey 落在 `login-pending.json`，5 分钟内没扫就作废，poll 会返回 `NO_PENDING_LOGIN`。
skill 里写清楚：过期就重新 start，把新图再发一次。

**Hermes 没有"发图工具"，机制是回复里带 `MEDIA:<绝对路径>`。**
`gateway/platforms/base.py::extract_media` 解析这个标记，网关自动上传发出。不知道这一点的话，
AI 拿到 PNG 路径也不知道怎么让图片真的出现在聊天里。

## 补记：官方取链通道（同日）

**以为登录只影响"能看见什么"，实测还能直接取到更高的音质。**
`/api/song/enhance/player/url` 带账号 cookie 时，VIP 账号能拿到 lossless / hires 的**真实地址**：
`アイドル` 拿到 24bit FLAC、86MB、3.2Mbps。匿名时同一端点 `url` 恒为 null 且 `code` 仍是 200。
→ 加了 `official.ts`，排在洛雪音源之前；拿不到才回落。

**以为第一次请求 403 是防盗链，实测是"地址刚签发"的时序问题。**
第一轮探测全部 403（返回 238 字节的 HTML），第二轮同样请求全部 200。
改成失败后退避重试 3 次（400ms × n），实测都能过。

**官方能给的比音源多，但不是万能。**
周杰伦《晴天》(186016) 官方和音源都拿不到：官方 `url` 为 null（下架），qdy 的网易云 404、酷我 410。
《床边故事》官方也不给，但酷我音源能给 24bit —— 所以两条路线缺一不可。

## 补记二：曲库规格与订阅（同日）

**以为曲库存 quality 就够，实测回答不了"哪些能升级"。**
`quality` 存的是档位名（`flac` / `24bit`），看不出是 16bit 还是 24bit。NAS 上回填 14 首后发现：
10 首是 44.1k/16（CD 规格）、1 首未知、只有 3 首真 24bit。只看档位名会误以为"大部分是无损"。
→ 加 `sample_rate` / `bits_per_sample` / `channels` 三列，`have --refresh` 读文件头回填。

**"44k" 是错的写法。** `round(44100/1000)` 得 44，把 44.1kHz 抹成 44k。改成保留一位小数。

**以为订阅该按上架时间判断新歌，实测不可靠。**
网易云 `publishTime` 对重发、精选集都不准（同一首歌在不同专辑里日期不同）。改用**曲目 id 集合差集**：
存上次见到的 id 列表，下次取回来做差。

**以为订阅第一次就该把现有的都下了，那等于把整个歌单重下一遍。**
第一次只记基线、不开任务。要下已有的得显式 `--download-existing`。

**验证方式**：在 NAS 上订阅一个 6 首歌单 → 只记基线（0 任务）；手动从快照删掉一首 → 再跑一次，
识别出 1 首新歌、开了任务、下好《浆果》。全链路通了。
